# Subscription Analytics Dashboard (Power BI)

Four-page Power BI dashboard built on the cleaned PostgreSQL subscription data (synthetic dataset: 15,000 users, 21,000 payments).

**Key findings**
- Users who completed onboarding converted at 29.3% vs 4.3% for those who did not.
- Feature X users cancelled at 31.1% vs 49.9% for non-users.
- Acquisition channel made little difference to conversion (18.6%-19.9%).
- Pro plan earned the most revenue (46%) and had the highest cancellation rate (46.8%).
